# Sol initial profile

`sol_profile.json` contains the 4 x 32 Hermite coefficients of the single fixed initial profile used in the Sol comparisons. Hermite frequency is 8, the center is log(k0/l0)/2, and the fixed orbit is (1,0). Initial-data construction metadata is retained for reproducibility; a frozen matrix eigenvalue is not a conserved physical frequency. The profile is not changed between spatial, window and time comparisons.
